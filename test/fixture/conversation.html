Here is the panel styling and the two helpers that go with it.

Panel styling

.panel {
  display: grid;
  gap: 12px;
  padding: 16px;
  border-radius: 10px;
}

Install it with:

npm install

Then the renderer:

function renderCart(items) {
  const total = items.reduce((n, i) => n + i.price, 0);
  return { count: items.length, total };
}

And wiring it up:

const el = document.querySelector('.cart');
el.addEventListener('click', wireUp);
function wireUp() { renderCart([]); }

The seed script:

import random

def seed(n):
    return [random.random() for _ in range(n)]

Run it with:

python seed.py 100
